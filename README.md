# Lumina-1

Lumina-1 is the first version of a personal Large Language Model (LLM) project inspired by humanity's greatest achievements in knowledge, science, exploration, engineering, and discovery.

## Milestone 1 — Foundation

This milestone establishes the project and introduces HTML, CSS, JavaScript, Python, and Git/GitHub.

### Structure

```text
Lumina-1/
├── README.md
├── LICENSE
├── .gitignore
├── website/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── 01-python/
    ├── calculator.py
    ├── tokenizer.py
    └── memory.py
```

Open `website/index.html` in a browser to try the first interface.

The chat is currently a frontend prototype. It does not contain a real language model yet.

Run the Python calculator with:

```bash
python3 01-python/calculator.py
```

The tokenizer and memory programs are intentionally simple. They will evolve in later milestones.
