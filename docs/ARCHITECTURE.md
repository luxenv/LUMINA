# Lumina-1 architecture

The migration branch adds an organized layout without deleting the original milestone folders.

- `src/core/`: current character-model training and generation.
- `src/model/`: neural and transformer experiments.
- `src/server/`: one HTTP entry point for local and hosted use.
- `web/`: static browser assets served by the Python server.
- `deploy/`: container and platform configuration.
- Original folders remain available for compatibility and historical milestone work.

Runtime flow: the browser calls `POST /api/chat`; `src/server/app.py` loads the model generated by `src/core/train.py` and returns generated text.
